# Conciencia Joven Internacional

Sitio estático de una sola página para [concienciajoven.com](https://concienciajoven.com). Fondo blanco, tipografía Nunito y colores de grupo usados solo como acentos.

## Cómo verlo

Abre `index.html` en el navegador o activa GitHub Pages en la raíz del repositorio.

## Archivos

```
index.html          Página única
css/styles.css      Estilos sólidos, sin transparencias
js/app.js           Menú, scroll, FAQ, formulario y contactos
assets/cruz.svg     Cruz sencilla
assets/favicon.svg  Favicon
```

## Contactos

Edita el objeto `CONTACTOS` al inicio de `js/app.js`.
